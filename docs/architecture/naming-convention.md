# Naming Convention

## Vue Components

### Page Sections

- Convention: PascalCase + `Section` suffix
- Example:
  - HeroSection.vue
  - FaqSection.vue
  - CtaSection.vue

---

### Reusable Base Components

- Convention: `Base` + PascalCase
- Example:
  - BaseButton.vue
  - BaseInput.vue

---

### Composables

- Convention: `use` + PascalCase
- Example:
  - useScrollAnimation.js
  - useAuth.js

---

### SCSS Partials

- Convention: `_lowercase.scss`
- Example:
  - \_variables.scss
  - \_reset.scss

---

### Assets

- Convention: lowercase folders
- Example:
  - assets/icons/
  - assets/social/
  - assets/ui/
